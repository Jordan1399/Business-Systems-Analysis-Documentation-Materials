# Business Systems Analysis Documentation Materials

Resources & Templates for BSA documentation

This repository contains reviewed business systems analysis and project documentation resources, organized by topic:

## Business Rules

`Business Rules/Business Rules Classification.xlsx` provides classifications and examples for restrictions, guidelines, computations, inferences, timing rules, and triggers. Use it to help identify and describe the kinds of rules that govern business operations.

## Interface Control Document

`Interface_Control_Document_Template/231160_InterfaceControlDocument.docx` is a CMS IT Governance template for documenting interfaces between systems. It includes sections for interface overviews, assumptions and constraints, data transfer, detailed interface requirements, security and integrity, quality assurance, approvals, and author instructions. Use it to define interface behavior, exchanged data, protocols, responsibilities, and verification expectations.

## Non-Functional Requirements

`Non-Functional Requirements Checklist/NFR Checklist- Supplementary Specification Guide.xlsx` lists non-functional requirement markers and definitions, including availability, auditability, authentication, compatibility, data integrity, performance, privacy, reliability, security, and usability. Use it as a prompt when eliciting and documenting quality attributes and operational constraints.

- `Feasibility Report/Feasibility_Report_Template.pdf` — contains a filled-in preparer name.
- `Root-Cause Analysis/Ishikawa(Fishbone) Templates/Copy of Fishbone diagram worksheet - Color.pdf` — contains a completed example with a name and date.
- `Root-Cause Analysis/Ishikawa(Fishbone) Templates/Fishbone-Diagram-GLSS-v4.xlsx` — contains personal creator/editor metadata.
- `Stakeholder Analysis/Example RACI Diagram.xls` — contains a person's name in the workbook.
- `Stakeholder Analysis/RACI Matrix.xlsx` — states that the template is for private use only and prohibits posting copies or modifications on websites.
- `Project Charter/Project-Charter.xlsx` — contains personal creator/editor metadata.
- `Project Charter/Project-Charter-Template-Institute-of-Project-Management.docx` — contains a personal editor name in its metadata.

## Adapt templates to your project

Templates are starting points, not finished project documents. Adapt each one to the project's scope, stakeholders, organization, applicable standards, and governance requirements; replace example material and review privacy, security, accessibility, and licensing considerations before sharing completed documents.
